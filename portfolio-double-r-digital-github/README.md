# Portfolio Double R Digital

Portfolio statique de Double R Digital réalisé avec HTML, CSS et JavaScript.

## Projet présenté

- [Fich'Antier](https://fichantier.fr)

## Lancer localement

Ouvrir directement `index.html`, ou utiliser l'extension Live Server dans VS Code.

## Publication GitHub Pages

Dans les paramètres du dépôt :

1. Ouvrir **Settings > Pages**
2. Choisir **Deploy from a branch**
3. Sélectionner la branche **main**
4. Sélectionner le dossier **/root**
